# Ejemplo de resultados de CobDosel

Informe y CSV de una foto de cobertura del dosel, tal como los produce «Cobertura del dosel» (CobDosel 1.1.1; las descripciones del CSV se actualizaron a las de 1.1.2, los valores no cambian).

- **[Informe_CobDosel_ejemplo.html](https://jfallas56-cr.github.io/CobDosel/ejemplos/Informe_CobDosel_ejemplo.html)**: informe de una foto (Índice CaCo, detalle por anillos con cobertura llevada a la vertical, peso y aporte al CaCo, tabla por sectores, figuras). GitHub muestra el código de un archivo HTML; para verlo como página use el enlace (GitHub Pages) o descárguelo y ábralo en el navegador.
- **[Resultados_CobDosel_ejemplo.csv](Resultados_CobDosel_ejemplo.csv)**: el CSV de la misma foto, una fila por variable (`variable`, `descripcion`, `valor`), con separador «;» y coma decimal.

**Foto:** teléfono Google Pixel 10, cámara principal (lente rectilínea), 18 de junio de 2026, máscara de horizonte de 63° (0–27° cenitales), 4 anillos, nivel de corte 225 recomendado (log-normal), canal azul + rojo. Sitio «Prueba». La foto no tiene coordenadas GNSS.

**Resultado:** Índice CaCo 97,34 %.
